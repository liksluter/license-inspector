# Плагин для проверки лицензий подключаемых зависимостей

Сканирует зависимости проекта, находит их лицензии и блокирует сборку, если обнаружена зависимость с запрещенной лицензией. По-умолчанию список разрешенных лицензий содержит лицензии типа permissive: `MIT`, `Apache 2.0` и `BSD`.

## Фильтры лицензий и зависимостей

Плагин добавляет расширение `licenseInspector`, которое содержит 2 фильтра:
* `allowedLicenses` - список разрешенных лицензий, по-умолчанию содержит 3 permissive лицензии `MIT`, `Apache 2.0` и `BSD`
* `ignoredDependencies` - список игнорируемых при проверке зависимостей
